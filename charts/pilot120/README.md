# Composition of the 120-family pilot

These charts describe selected data, not model performance. The complete report is [here](../../research/PILOT120_DATASET_2026_10_30.md).

- `composition`: counts and percentages of 120 distinct source-problem families. Each family has three teaching exercises. Whole-dataset percentages use 120 as their denominator.
- `topic-composition`: one provisional primary topic per family, with percentages within each 40-family subject. Other concepts may overlap. This is not full syllabus coverage.
- `token-composition`: measured assistant-target tokens from one copy of all 360 exercises, with 78,922 tokens as the denominator. This is not an adopted training schedule or loss weighting.

Reasoning demand is a provisional source-based assessment, not calibrated difficulty. A valid or flawed checking step is something the model is asked to assess; it does not label the complete solution as correct or incorrect.

The private source images, teaching targets, family-level inventory and review evidence are not included. No model training occurred while preparing this package.
